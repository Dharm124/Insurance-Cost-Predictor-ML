# 🏥Insurance Cost Predictor ML

This is my first Machine Learning project, built during my beginner learning phase in ML.

The project predicts medical insurance charges based on user details such as age, BMI, smoking status, number of children, gender, and region.

## 🎯Project Goal

The main goal of this project is to understand the basic Machine Learning workflow using Simple Linear Regression and Multiple Linear Regression.

This project helped me connect theory with practical implementation.

## 📌Current Version

This is Version 1 of the project.

In this version, I focused on:

- Data loading
- Exploratory Data Analysis
- Feature encoding
- Feature engineering
- Simple Linear Regression
- Multiple Linear Regression
- Model evaluation

## 📊Dataset Features

The dataset contains the following columns:

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges

## 🤖Models Used

Since I am currently learning regression, I used:

1. Simple Linear Regression
2. Multiple Linear Regression

In future versions, I will add more models after learning them properly.

## 📈Evaluation Metrics

The model was evaluated using:

- R² Score
- Mean Absolute Error
- Mean Squared Error
- Root Mean Squared Error

## ✅Current Result

The Multiple Linear Regression model achieved around 84% R² score on test data.
